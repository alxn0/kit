name: wait
description: Pause before implementing — present a plan and wait for explicit confirmation
disable-model-invocation: true
---

Do not implement anything yet.

Before making any file changes, running any non-read-only commands, or otherwise acting on the task above, present a clear plan covering:

- Your understanding of what the user is asking for
- The concrete steps you intend to take (files to edit, commands to run)
- Any assumptions you're making
- Anything ambiguous you'd like the user to clarify or confirm

Then stop and wait for explicit user confirmation. Do not proceed until the user replies approving the plan (or with corrections).

If the user has already given a plan and is asking you to refine it, refine the plan only — still do not implement.
